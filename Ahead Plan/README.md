# DataPillars Ahead Plan

Prepared: 15 September 2026

This folder converts the website launch into two controlled follow-on workstreams:

1. [SEO and Growth Plan](./SEO-and-Growth-Plan.md) — technical readiness, search-console setup, content, authority building, conversion measurement and a 90-day execution sequence.
2. [Professional Email Setup Plan](./Professional-Email-Setup-Plan.md) — mailbox provider choice, Tasjeel DNS changes, two founder mailboxes, shared addresses, email authentication, Resend separation and security checks.

## Recommended order

1. Finish the website and enquiry-form validation.
2. Set up professional mailboxes and authentication.
3. Verify Google Search Console and Bing Webmaster Tools.
4. Establish the measurement baseline.
5. Publish the first service pages and evidence-led articles.
6. Start outreach and authority building only after the landing pages are ready to convert that traffic.

The website is the foundation. Search visibility will come from a sustained combination of useful content, technical health, credible evidence, relevant mentions and conversion learning—not from a one-time metadata exercise.
